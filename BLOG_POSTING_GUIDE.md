## 📝 How to Create a Blog Post

### Step-by-Step Process

#### 1. Access the Blog Management Tab

- After logging in, you'll see three tabs at the top:
  - Contact Submissions
  - **Blog Posts** ← Click this one
  - Chatbot Knowledge
- Click on **"Blog Posts"** to access blog management

#### 2. Start a New Post

- Click the **"+ New Post"** button (blue gradient button in top right)
- A blog editor form will appear with the following fields:

#### 3. Fill Out Blog Post Details

**Required Fields:**

1. **Title** (text field)
   - Enter your blog post headline
   - Example: "5 Ways AI Can Transform Your Business Operations"

2. **Excerpt** (text field)
   - Write a brief 1-2 sentence summary
   - This appears on the blog list page
   - Example: "Discover how AI-powered automation can save 35+ hours weekly and boost efficiency by 70%."

3. **Content** (large text area - supports Markdown)
   - Write your full blog post here
   - Use Markdown formatting (see formatting guide below)
   - You can preview before publishing

4. **Author** (text field)
   - Default: "Daniel Schley"
   - Change if needed

5. **Published Date & Time**
   - Select the date and time for the post
   - Can be backdated or future-dated

6. **Read Time** (minutes)
   - Estimate: 5 minutes per 1000 words
   - Example: 1000-word post = 5 minutes

7. **Tags** (comma-separated)
   - Enter relevant keywords
   - Example: AI, Automation, Business Operations, ROI
   - Press Enter or comma to add each tag

**Optional Settings:**

8. **Featured Post** (checkbox)
   - Check this to highlight the post on your homepage
   - Only use for your best/most important posts

9. **Published** (checkbox)
   - Check this to make the post live on your website
   - Uncheck to save as draft

#### 4. Preview Your Post (Recommended)

- Click the **"Preview"** button (eye icon)
- Review how your post will look
- Check formatting, images, links
- Click "Close Preview" when done

#### 5. Save or Publish

- **Save Draft:** Click **"Save"** with "Published" unchecked
- **Publish Live:** Click **"Save"** with "Published" checked
- You'll see a success message

#### 6. View Your Published Post

- Go to: **https://aiopsexpert.com**
- Scroll down to the "Latest Insights" section
- Your post will appear there

### Images

Images make your blog posts more engaging and professional. Here's how to add them:

**Basic Image Syntax:**
```markdown
![Alt text description](https://example.com/image.jpg)
```

**Step-by-Step Process:**

1. **Find or Upload Your Image**
   - Use free stock photos (see recommended sites below)
   - OR upload your own image to an image hosting service

2. **Get the Image URL**
   - The URL must be a direct link to the image file
   - It should end in .jpg, .png, .gif, or .webp
   - Example: `https://images.pexels.com/photos/123456/photo.jpg`

3. **Add to Your Blog Post**
   ```markdown
   ![AI Dashboard Example](https://images.pexels.com/photos/8386440/pexels-photo-8386440.jpeg)
   ```

4. **Alt Text Best Practices**
   - Describe what's in the image
   - Keep it concise (10-15 words)
   - Include keywords when relevant
   - Example: "Business owner reviewing AI analytics dashboard"

**Free Stock Photo Sites (Recommended):**

- **Pexels.com** (Best for business/tech images)
  - Search for: "artificial intelligence", "business technology", "data analytics"
  - Click photo → Right-click → "Copy image address"
  - Example URL: `https://images.pexels.com/photos/8386440/pexels-photo-8386440.jpeg`

- **Unsplash.com** (High-quality professional images)
  - Search your topic
  - Click "Download" → Right-click → "Copy image address"
  - Example URL: `https://images.unsplash.com/photo-1234567890`

- **Pixabay.com** (Wide variety, free commercial use)

**Image Hosting Services (For Your Own Photos):**

If you want to use your own images:

1. **Imgur.com** (Free & Easy)
   - Go to imgur.com
   - Click "New post"
   - Upload your image
   - Right-click image → "Copy image address"
   - Use the direct link (ends with .jpg or .png)

2. **Cloudinary.com** (Professional, has free tier)
3. **ImgBB.com** (Simple, no account needed)

**Image Placement Tips:**

- Add an image at the start (after the main heading)
- Use 1-3 images per 1000 words
- Place images near relevant content
- Break up long text sections with visuals
- Use relevant, high-quality images only

**Common Mistakes to Avoid:**

❌ Using image URLs that require login
❌ Using low-resolution or blurry images
❌ Forgetting alt text (important for SEO)
❌ Using copyrighted images without permission
❌ Adding too many images (slows page load)

✅ Use direct image URLs (https://...)
✅ Choose high-quality, relevant images
✅ Always include descriptive alt text
✅ Use free stock photos or licensed images
✅ Keep images optimized (under 500KB when possible)

## 📋 Blog Post Best Practices

### Content Guidelines

1. **Headline Best Practices:**
   - Keep it under 60 characters
   - Make it compelling and benefit-focused
   - Use numbers when possible ("5 Ways to...", "3 Steps to...")
   - Include keywords naturally

2. **Excerpt Tips:**
   - 120-160 characters ideal
   - Summarize the key benefit
   - Make readers want to click
   - Include a call-to-action

3. **Content Structure:**
   - Start with a compelling opening paragraph
   - Use subheadings (H2, H3) to break up content
   - Keep paragraphs short (2-4 sentences)
   - Use bullet points and numbered lists
   - Include examples and case studies
   - End with a clear call-to-action

4. **SEO Optimization:**
   - Include main keyword in title
   - Use keywords naturally in content
   - Add relevant tags
   - Include internal links to your services
   - Keep posts 800-2000 words for best SEO

5. **Visual Elements:**
   - Add at least one image
   - Use stock photos from Pexels or Unsplash
   - Include screenshots when relevant
   - Break up long text blocks

### Writing Style

- **Voice:** Professional but conversational
- **Tone:** Helpful, authoritative, confident
- **Perspective:** Mix of "I" (personal) and "you" (direct)
- **Technical Level:** Explain complex concepts simply
- **Length:** 800-1500 words is ideal

1. **Educational Content:**

## 🆘 Troubleshooting

### Can't Log In?

**Problem:** "Failed to fetch" error

**Solutions:**
1. Check your internet connection
2. Clear browser cache and cookies
3. Try incognito/private browsing mode
4. Make sure you're using the correct password
5. Check if email confirmation is required (check your email)

### Don't Remember Password?

1. On the login screen, you should see a "Forgot password?" link
2. If not, you can use the Supabase dashboard to reset
3. Or create a new admin account at /admin-signup

### Post Not Showing on Website?

**Check:**
1. Is the "Published" checkbox checked?
2. Is the publish date in the past (not future)?
3. Did you click "Save"?
4. Try refreshing the website (Ctrl+R or Cmd+R)

### Formatting Looks Wrong?

1. Click "Preview" to check formatting before saving
2. Make sure Markdown syntax is correct
3. Check for unclosed formatting tags
4. Ensure proper spacing around headings and lists

### Images Not Loading?

- Make sure image URLs are publicly accessible
- Use https:// URLs (not http://)
- Test the image URL in a new browser tab
- Consider using image hosting services (Imgur, Cloudinary)
