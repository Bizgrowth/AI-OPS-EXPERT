🔌 MCP SETUP GUIDE

How to Connect AI Agents to Any Tool

MCP (Model Context Protocol) is the universal plug-in standard for AI. Here's everything you need to know to set it up — and which AI models support it.

🤖 Which AI Models Can Use MCPs?

MCP was created by Anthropic and donated to the Linux Foundation in Dec 2025, making it an open standard. All major AI platforms now support it:

✅ Claude (Anthropic)
Native MCP support. First-class integration in Claude Desktop, Claude Code, and Antigravity.
✅ GPT-4 / ChatGPT (OpenAI)
OpenAI adopted MCP in early 2025. Supported in Cursor, Windsurf, and API integrations.
✅ Gemini (Google)
Google DeepMind adopted MCP in 2025. Supported via Gemini API and agent frameworks.
✅ Open Source Models
Llama, Mistral, and others support MCP via frameworks like LangChain, LlamaIndex, and n8n.

⚙️ How to Set Up an MCP — Step by Step

Works with Claude Desktop, Cursor, Windsurf, VS Code + Copilot, and more.

1
Choose Your MCP Server
Browse the official MCP registry, Glama marketplace, or search GitHub for the tool you want to connect (Composio, Firecrawl, Playwright, etc.).
2
Get an API Key
Most MCPs require an API key from the service (e.g., Composio dashboard, Firecrawl.dev). Store it as an environment variable — never hardcode it in your config.
3
Add to Your AI Client Config
Every MCP-compatible client uses the same JSON format. Add this to your config file:
{
  "mcpServers": {
    "composio": {
      "command": "npx",
      "args": ["-y", "@composio/mcp@latest"],
      "env": {
        "COMPOSIO_API_KEY": "YOUR_KEY_HERE"
      }
    }
  }
}
4
Config File Locations by Client
Claude Desktop
~/AppData/Roaming/Claude/claude_desktop_config.json
Cursor
~/.cursor/mcp.json
VS Code + Copilot
.vscode/mcp.json
Windsurf
~/.codeium/windsurf/mcp_config.json
5
Restart & Use It
Restart your AI client. The new tools will appear. Start with read-only access, test with simple prompts, then expand permissions as you gain confidence in the agent's behavior.
