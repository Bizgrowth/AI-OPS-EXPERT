🔗 Back to Demo Center - Implementation Guide

Add this button to all your demo pages to enable navigation back to the AI Portfolio section

📋 Quick Instructions:
  1. Copy the HTML code below
  2. Paste it at the top of each demo page (right after the opening <body> tag)
  3. The button will automatically detect the return URL and navigate back to the Demo Center

📝 HTML Code to Add to Each Demo Page

Copy this entire code block and paste it into your demo pages:

<!-- Back to Demo Center Button -->
<div id="demo-back-button" style="
    position: fixed;
    top: 20px;
    left: 20px;
    z-index: 9999;
    animation: slideIn 0.5s ease-out;
">
    <a id="back-to-demo-link" href="#" style="
        display: inline-flex;
        align-items: center;
        gap: 8px;
        background: rgba(15, 23, 42, 0.95);
        backdrop-filter: blur(10px);
        color: #06b6d4;
        padding: 12px 20px;
        border-radius: 8px;
        text-decoration: none;
        font-weight: 600;
        font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
        font-size: 14px;
        border: 1px solid rgba(51, 65, 85, 0.8);
        box-shadow: 0 4px 6px rgba(0, 0, 0, 0.3);
        transition: all 0.3s ease;
    " onmouseover="this.style.background='rgba(30, 41, 59, 0.95)'; this.style.borderColor='#06b6d4'; this.style.transform='translateX(-4px)';" onmouseout="this.style.background='rgba(15, 23, 42, 0.95)'; this.style.borderColor='rgba(51, 65, 85, 0.8)'; this.style.transform='translateX(0)';">
        <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
            <path d="M19 12H5M12 19l-7-7 7-7"/>
        </svg>
        <span>Back to Demo Center</span>
    </a>
</div>

<style>
    @keyframes slideIn {
        from {
            opacity: 0;
            transform: translateX(-20px);
        }
        to {
            opacity: 1;
            transform: translateX(0);
        }
    }

    @media (max-width: 768px) {
        #demo-back-button {
            top: 10px !important;
            left: 10px !important;
        }
        #back-to-demo-link {
            padding: 10px 16px !important;
            font-size: 13px !important;
        }
    }
</style>

<script>
    // Automatically set the return URL from the query parameter
    (function() {
        const urlParams = new URLSearchParams(window.location.search);
        const returnUrl = urlParams.get('returnUrl');
        const backButton = document.getElementById('back-to-demo-link');

        if (returnUrl) {
            backButton.href = decodeURIComponent(returnUrl);
        } else {
            // Fallback to main portfolio section if no returnUrl provided
            backButton.href = 'https://aiopsexpert.com#ai-portfolio';
        }

        // Handle click with smooth transition
        backButton.addEventListener('click', function(e) {
            if (window.opener) {
                e.preventDefault();
                window.close();
                if (!window.closed) {
                    window.location.href = this.href;
                }
            }
        });
    })();
</script>
<!-- End Back to Demo Center Button -->

💡 How It Works:
  • When users click "Launch Live Demo", the URL includes a returnUrl parameter
  • The button automatically reads this parameter and sets the correct return destination
  • Users click "Back to Demo Center" and return to exactly where they were
  • If opened directly (without the parameter), it defaults to the main Demo Center
